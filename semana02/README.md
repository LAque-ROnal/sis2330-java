# Semana 02 - Sistema de Calificaciones

## Descripcion

Sistema de Calificaciones: arrays 2D, metodos static, Scanner con validacion de InputMismatchException.

## Como se ejecuta

    cd src
    javac SistemaCalificaciones.java
    java SistemaCalificaciones

## Que se aprendio

Tipos primitivos, operadores, control de flujo, arrays y metodos, sin usar clases propias.
